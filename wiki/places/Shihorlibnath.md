# Shihorlibnath

## Overview

Asher’s border reaches *to Carmel westward, and to Shihorlibnath* (26). The register names it as a western landmark; whether it is a stream, district, or town is not stated. Not equated with [[Shihor]] on Egypt’s frontier (13:3).

Source: stored WEB Joshua 19:24–48. No precise modern site is assigned.
