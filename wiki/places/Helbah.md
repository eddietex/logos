# Helbah

## Overview

Named among Asher's seven cities not driven out (Judges 1:31, stored WEB). Not in Asher's list in Joshua 19 as the WEB reads it. Nothing else is said of it.

See [[The Tribes That Did Not Drive Out]]. Source: stored WEB Judges 1:30–33; Joshua 19:15, 24–31;
the Hebrew name (*ḥelbāh*) read in the WLC (OpenScriptures morphhb).
