# Baalath

## Overview

Named in Dan’s border list (41–46), for which no city total is given (44). Distinct from [[Baalath Beer]] in Simeon’s register (19:8). Judah’s border passes a Mount Baalah near Ekron (15:11); the different name is not silently equated.

Source: stored WEB Joshua 19:24–48. No precise modern site is assigned.
