# Zaphon

## Overview

Named among Gad’s valley towns with Beth Haram, Beth Nimrah, and Succoth (27). No modern identification is assigned.

Source: stored WEB Joshua 13:8–33.

### A possible reading at Judges 12:1

Ephraim *passed northward*, *wayyaʿăbōr ṣāpônâ* (Judges 12:1, WLC). The OpenScriptures tagging and the
WEB read *north* with the directional ending. The same consonants could be read as *to Zaphon*, this
valley town, which would put Ephraim's crossing near the Jordan in Gad's land. The wiki records the
possibility and does not decide it. See [[Shibboleth]]. Source: stored WEB Joshua 13:27; Judges 12:1;
Hebrew WLC (OpenScriptures morphhb), 2026-11-16.
