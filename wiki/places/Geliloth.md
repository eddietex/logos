# Geliloth

## Overview

A southern boundary landmark opposite the ascent of Adummim, before the descent to Bohan’s stone (17). Joshua 15:7 names Gilgal opposite the same ascent; correspondence does not establish identity, so the names remain separate.

Source: stored WEB Joshua 18:11–28.
