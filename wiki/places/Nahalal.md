# Nahalal

## Overview

### Nahalol — Judges 1:30

Judges 1:30 names *Nahalol* among Zebulun's cities not driven out. The WLC tags *nahălōl* with the same lemma as Joshua 19:15's *nahălāl*, and both are Zebulun's, so the wiki files the two spellings here.

See [[The Tribes That Did Not Drive Out]]. Source: stored WEB Judges 1:22–36.

### Levitical cities — Joshua 21:1–42

Allocated with its suburbs from Zebulun to Merari’s descendants (21:35).

See [[The Cities of the Levites]]. Source: stored WEB Joshua 21:1–42.

Named in Zebulun’s city register, whose stated total is twelve cities with villages (15–16). No individual capture or modern identification is supplied.

Source: stored WEB Joshua 19:1–23. No precise modern site is assigned.
