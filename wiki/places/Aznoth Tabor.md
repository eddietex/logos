# Aznoth Tabor

## Overview

Naphtali’s border turns westward to Aznoth Tabor (34) before going out to Hukkok. Its name shares an element with [[Tabor]] and [[Chisloth Tabor]]; the text does not explain the relationship.

Source: stored WEB Joshua 19:24–48. No precise modern site is assigned.
