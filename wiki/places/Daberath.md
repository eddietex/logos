# Daberath

## Overview

### Levitical cities — Joshua 21:1–42

Allocated with its suburbs from Issachar to Gershon’s descendants (21:28).  Joshua 19:12 places Daberath on Zebulun’s boundary, while this allocation is from Issachar. Border location may explain the overlap, but the text supplies no administrative explanation.

See [[The Cities of the Levites]]. Source: stored WEB Joshua 21:1–42.

On Zebulun’s boundary after Chisloth Tabor, before the ascent to Japhia (12).

Source: stored WEB Joshua 19:1–23. No precise modern site is assigned.
