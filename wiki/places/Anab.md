# Anab

## Overview

### Judah’s cities — Joshua 15:20–63

Listed in the first hill-country group (50). 11:21 named it among the places the Anakim were cut off from; it is now allotted to Judah.

See [[The Cities of Judah]]. Source: stored WEB Joshua 15:20–63.

One of the places from which Joshua cuts off the Anakim, named with Hebron and Debir (11:21). Joshua 15:50 later lists Anab among the cities of Judah's hill country. No separate capture narrative is given.

Source: stored WEB Joshua 11:16–23. No modern identification is assigned.
