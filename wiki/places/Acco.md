# Acco

## Overview

First of Asher's seven cities whose inhabitants were not driven out (Judges 1:31, stored WEB). It does not appear in Asher's list in Joshua 19 as the WEB reads it. The text says nothing more about it here; no modern site is assigned on this page.

See [[The Tribes That Did Not Drive Out]]. Source: stored WEB Judges 1:30–33; Joshua 19:15, 24–31;
the Hebrew name (*ʿakkô*) read in the WLC (OpenScriptures morphhb).
