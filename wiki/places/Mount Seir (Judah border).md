# Mount Seir (Judah border)

## Overview

A mountain reached westward from Baalah on Judah’s northern boundary (10). Kept distinct from the Seir associated with Edom; the shared name does not make this route run through Edom.

Source: stored WEB Joshua 15:1–12. No precise modern location or unstated biography is asserted.
