# Baal Meon

## Overview

Built and renamed by the children of Reuben (Numbers 32:38); the request of 32:3 names a *Beon*, which the
wiki takes as the same town. The first part of the name is the god Baal, and the parenthesis *their names
being changed* follows it; Rashi reads this as the removal of idol names (Sefaria English). The new name is
not given, and the old one survived: Joshua 13:17 lists *Beth Baal Meon* in Reuben's border (WEB via
bible-api.com, not yet ingested).

Source: stored WEB Numbers 32.
