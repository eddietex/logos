# Aram (place)

## Overview

Balaam’s first oracle names Aram and the mountains of the East as the region from which Balak
brought him (23:7). This broad regional designation is not automatically identical with the narrower
Aram Naharaim of the patriarchal accounts. It is recalled provenance, not the present scene.

Source: stored WEB Numbers 22:36–23:26.
