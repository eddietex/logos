# Beth Dagon (Asher)

## Overview

Asher’s border turns *toward the sunrise to Beth Dagon* (27). Distinct from [[Beth Dagon (Judah)]] in Judah’s lowland (15:41); the shared name is not treated as one site.

Source: stored WEB Joshua 19:24–48. No precise modern site is assigned.
