# Shaalabbin

## Overview

### Shaalbim — Judges 1:35

Judges 1:35 names *Shaalbim* among the places where the Amorites *would dwell*. The WLC tags it with the same lemma as Joshua 19:42's *Shaalabbin*, in Dan's list beside Aijalon, so the notice is filed here.

See [[The Tribes That Did Not Drive Out]]. Source: stored WEB Judges 1:22–36.

Named in Dan’s border list (41–46), for which no city total is given (42). No individual capture or modern site is supplied.

Source: stored WEB Joshua 19:24–48. No precise modern site is assigned.
