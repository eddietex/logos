# Rimmon (Zebulun)

## Overview

Zebulun’s boundary goes out at Rimmon, which stretches to Neah (13). Distinguished from Rimmon (Negev) in Simeon’s list (7).

Source: stored WEB Joshua 19:1–23. No precise modern site is assigned.
