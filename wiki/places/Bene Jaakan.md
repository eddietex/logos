# Bene Jaakan

## Overview

### Renewed tablets and onward journey — Deuteronomy 10:1–11

Compare Beeroth Bene Jaakan in Deuteronomy 10:6, from which Israel travels to Moserah. Numbers 33:31
instead has Moseroth followed by Bene Jaakan. If these names designate the same pair of stations,
the direction is reversed; neither passage explains a retracing of the route.

See [[New Tablets and the Journey Onward]]. Source: stored WEB Deuteronomy 10:1–11.

The itinerary places this stage after [[Moseroth]] and before [[Hor Haggidgad]].

Source: stored WEB Numbers 33:1–49. No modern site is assigned.
