# Raw sources

Immutable. The agent reads from here but never edits these files — corrections happen by adding
new raw material, not editing old material.

## `bible/`

One file per book, e.g. `bible/Genesis.md`, containing the **World English Bible (WEB)** text
(public domain). Populated book-by-book as ingestion reaches that book, not all at once —
either fetched by the agent or pasted in by you.

## `assets/`

Downloaded images (maps, charts, diagrams) referenced by wiki pages. If you use the Obsidian Web
Clipper on secondary sources later, point its attachment folder here (see the setup note in the
root `README.md`).
